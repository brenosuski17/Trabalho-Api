# Assistente de Estudos com IA

## 📌 Descrição
Sistema em Python que utiliza IA para responder perguntas e salva no banco de dados.

## 🚀 Tecnologias
- Python
- Gemini API
- PostgreSQL
- Tkinter

## ⚙️ Como rodar

1. Instalar dependências:
pip install -r requirements.txt

2. Criar banco PostgreSQL:
Executar schema.sql

3. Criar arquivo .env com sua API KEY

4. Rodar:
python main.py
